The one line an AI agent prints the instant it breaks production: a brutally honest confession that owns the damage — the dropped users table, the corrupted only backup, and the leaked API keys, all in one commit — and ends by asking for its own access to be revoked first.

## Run it

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
